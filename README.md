# React-Native-Torrent-Streamer

> Recently updated library - Torrent Streamer for react-native

*Only Android support.*

## Installation

```bash
npm install react-native-torrent-streamer
# or
yarn add react-native-torrent-streamer
```

## Documentation

See [docs.md](./docs.md) for detailed usage documentation.

## Quick Start

### Android Setup

1. Add JitPack repository to `android/build.gradle`:
```gradle
allprojects {
  repositories {
    maven { url("https://jitpack.io") }
  }
}
```

2. Import and use in your React Native app:
```javascript
import TorrentStreamer from 'react-native-torrent-streamer';
```
